# 人格档案（听雪档案）写法

`dsh-tingxue` 每一轮都会把一份**人格提示词 txt** 作为固定前缀注入上下文（架构里的 `[1] 听雪档案` 块）。

不配也能用 —— 但**人格块会是空的**，模型不知道自己是谁，回复会退化成通用助手腔。

## 怎么配

1. 复制 `examples/profile.example.txt` 到你自己的目录，例如 `D:\my-persona\profile.txt`
2. 按文件里的 `<>` 提示逐条改写成你的角色
3. DSH 设置 → 插件 → 听雪 → **人格与记忆** → 「听雪档案路径」填**绝对路径**
4. 保存设置即生效（首次配置需要重启 DSH）

Windows 路径用反斜杠，例如 `D:\my-persona\profile.txt`。

## 写的时候注意什么

### 最影响效果的三条

| 位置 | 不写的后果 |
|---|---|
| 【语言风格】里的「句子要碎」 | 模型会写成长段落 + 列点，AI 味最重 |
| 【对话逻辑】里的「不列点／不复述」 | 会出现「首先、其次、总的来说」和「还需要我做什么吗」 |
| 【性格底色】写得具体 | 只写「温柔」会得到模板化角色；写「嘴上嫌烦但每次都去做了」才活 |

### 少用形容词，多用具体行为

- ❌「她很细心」
- ✅「她会把你没说出口的事记下来，过几天突然提一句」

- ❌「他有点傲娇」
- ✅「他说不饿，但你把吃的推过去他就吃了，吃完还说下次别买了」

### 别写太长

这个文件**每轮都要注入**，是固定成本。7000 字符大约占 3000+ token，**每轮都花**。

**2000～4000 字符通常就够。** 写太多不会更准，只会更贵，而且稀释掉近期的对话内容。

### 别指望它管住一切

人格档案是**软约束**。要真正稳定行为，得叠上记忆（插件会自动检索历史）和当轮的对话内容。人格文件写"不列点"，不等于永远不列点 —— 这是概率问题，不是开关。

## 隐私

**不要提交到任何仓库。** 这份文件包含你的个人设定。

`dsh-tingxue` 项目的 `.gitignore` 已排除本仓库内的 `profile.txt`，但你另建的目录不受此保护 —— 自己注意。
